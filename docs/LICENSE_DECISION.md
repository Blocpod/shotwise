# License Decision

VQA Estimator Lab is licensed under the Apache License, Version 2.0.

## Rationale

Apache-2.0 is a permissive open-source license that is friendly to academic, startup,
and enterprise use. It also includes an explicit patent grant, which is important for
research software that may be used in commercial quantum algorithm tooling.

## Files

- `LICENSE`: full Apache-2.0 license text.
- `NOTICE`: project attribution notice.
- `pyproject.toml`: package metadata declares Apache-2.0.
